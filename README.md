# 视频剪辑小助手

选择一个总范围，批量删除不要的片段，将剩余内容按原视频顺序合并成一个 MP4。也可以切换为“只保留这些片段”。适合剪掉一两秒的口误、停顿或多处无用内容。

## 使用

1. 选择视频，填写总范围的开始和结束时间。
2. 选择“删除这些片段，合并剩余内容”。
3. 在片段清单中每行填写一个区间，用 `-` 分隔开始和结束时间。
4. 检查合并预览，点击“合并导出 MP4”。

例如原视频长 60 分钟，总范围填写 `1:36` 到 `5:36`，时间基准使用“原视频时间”，清单填写：

```text
2:00 - 3:00
4:12.500 - 4:14
```

软件保留 `1:36–2:00`、`3:00–4:12.500`、`4:14–5:36`，自动合并为一个视频。只删除第一行时，总输出为 3 分钟（总范围本身为 4 分钟）。

如果习惯从总范围起点计时，可将时间基准改成“总范围内时间”：总范围为 `1:36–5:36` 时，`0:24–1:24` 等价于原视频的 `2:00–3:00`。打开已经截取好的小视频时，总范围从 `0` 开始，时间直接使用该小视频播放器上的时间。

支持秒数（`96`）、分:秒（`1:36`）、时:分:秒（`00:01:36`）及毫秒（`1:36.250`）。片段按原视频时间排序；重叠和相邻区间自动合并。删除清单留空时导出整个总范围。无效、倒序、越界或删除全部内容会提示错误。

输出文件默认保存在原视频目录，名称为 `原文件名_edited.mp4`。已有文件不会被覆盖。可取消导出，临时文件会自动清理。

## 运行和构建

需要 Go（版本见 go.mod）、Fyne 的桌面构建环境，以及支持 `libx264` 和 AAC 的 FFmpeg。将 `ffmpeg` 和 `ffprobe`（Windows 为 `.exe`）放在软件同目录，或加入系统 PATH。

```sh
go run .
go build -o video-cut-gui .
go test ./...
```

Windows GUI 构建：

```sh
go build -ldflags="-H windowsgui" -o video-cut-gui.exe .
```

GitHub Actions 可构建 Windows 程序；下载程序后需另行准备上述 FFmpeg 工具。

## 精度与限制

使用 H.264 / AAC 重新编码后合并，避免流复制只能在关键帧附近切割的问题。时间可输入毫秒，实际视频切点受源视频帧率限制；编码会花费时间并有轻微画质损失。输出保留第一条视频轨和第一条音轨，支持无音轨视频，不保留字幕、额外音轨和章节。当前使用时间清单和文字预览，未内置视频播放窗口。

测试包括区间计算、相对计时、毫秒、输入错误，以及使用真实 FFmpeg 生成的带音轨和无音轨视频的导出、时长、取消和防覆盖验证。FFmpeg 不可用时集成测试会跳过。
