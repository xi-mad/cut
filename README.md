# 视频剪辑小助手

填写切分时间点，自动生成连续片段，勾选要保留的段，最后按原视频顺序合并成一个 MP4。

## 使用

1. 选择视频，填写总范围开始和结束时间。
2. 输入切分时间点，每行一个，也可用逗号、空格或分号分隔。
3. 在自动生成的片段列表中勾选要保留的段，取消不要的段。
4. 检查预览和总时长，点击“合并导出 MP4”。

例如总范围 `1:36` 到 `5:36`，输入：

```text
2:00, 3:00
```

生成三个独立的复选框：

- 保留第 1 段：`1:36 → 2:00`
- 保留第 2 段：`2:00 → 3:00`
- 保留第 3 段：`3:00 → 5:36`

取消第 2 段，即把第 1、3 段合并成 3 分钟的视频。提供“全部保留”和“全部取消”按钮。

切分点自动排序、去重；总范围开始之前和结束之后的切分点会提示错误。留空时总范围作为一整段。修改切分点后列表自动更新，起止时间完全相同的段保留之前的勾选状态，新生成的段默认保留，请检查后再导出。全部取消时不能导出。相邻的保留片段自动连续处理，避免多余接缝。

支持秒（`96`）、分:秒（`1:36`）、时:分:秒（`00:01:36`）以及毫秒（`1:36.250`）。默认使用原视频时间，也可切换成“总范围内时间”：总范围 `1:36–5:36` 时，`0:24, 1:24` 等价于原视频切分点 `2:00, 3:00`。片段列表和合并预览始终显示原视频时间。

输出文件默认保存在原视频目录，名称为 `原文件名_edited.mp4`。已有文件不会被覆盖。可取消导出，临时文件会自动清理。

## 运行和构建

需要 Go（版本见 go.mod）、Fyne 的桌面构建环境，以及支持 `libx264` 和 AAC 的 FFmpeg。将 `ffmpeg` 和 `ffprobe`（Windows 为 `.exe`）放在软件同目录，或加入系统 PATH。

```sh
go run .
go build -o video-cut-gui .
go test ./...
```

Windows GUI 构建：

```sh
go build -ldflags="-H windowsgui" -o video-cut-gui.exe .
```

GitHub Actions 可构建 Windows 程序；下载程序后需另行准备上述 FFmpeg 工具。

## 精度与限制

“关键帧快速剪辑”复选框默认不勾选。勾选后复制视频流，不重新编码视频，音频仍转 AAC，适合优先追求速度的场景。切点可能提前到上一关键帧，保留部分原本要删除的画面，实际时长也可能与预览不同；剪除一两秒的内容建议保持不勾选。源视频编码必须兼容 MP4，否则请使用默认的精确模式。

使用 H.264 / AAC 重新编码后合并，避免流复制只能在关键帧附近切割的问题。时间可输入毫秒，实际视频切点受源视频帧率限制；编码会花费时间并有轻微画质损失。输出保留第一条视频轨和第一条音轨，支持无音轨视频，不保留字幕、额外音轨和章节。当前使用时间清单和文字预览，未内置视频播放窗口。

测试包括切分点排序去重、片段勾选合并、相对计时、毫秒、输入错误，以及使用真实 FFmpeg 生成的带音轨和无音轨视频的导出、时长、取消和防覆盖验证。FFmpeg 不可用时集成测试会跳过。
